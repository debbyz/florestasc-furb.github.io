# FlorestaSC — proposta de novo site

Site estático do FlorestaSC (Inventário Florístico Florestal de Santa Catarina), migrado de floresta.sc.gov.br (Google Sites) em novembro de 2026.

- Publicado pelo GitHub Pages em https://florestasc-furb.github.io
- Página inicial: `index.html`; portal de dados: `dados.html`
- Estilos em `assets/css/site.css`; busca em `assets/js/busca.js` e `assets/js/site.js`
- Fotos e textos: FlorestaSC
